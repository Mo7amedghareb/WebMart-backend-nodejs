# WebMart Backend

WebMart Backend is a RESTful API for an e-commerce platform built with Node.js, Express.js, and MongoDB. It powers the WebMart frontend by handling authentication, product management, shopping cart operations, orders, and administrative features.

---

## Features

- User Authentication (JWT)
- User Registration & Login
- Product Management
- Category Management
- Shopping Cart
- Wishlist
- Order Management
- Checkout
- Admin Dashboard APIs
- User Profile Management
- Product Search & Filtering
- File Upload Support
- Error Handling & Validation
- Secure Password Hashing

## Getting Started

```bash
npm install
npm start
```

Create a `.env` file and configure:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
